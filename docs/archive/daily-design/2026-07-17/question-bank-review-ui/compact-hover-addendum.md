# Compact Hover Addendum

Status: approved by explicit user request on 2026-07-17.

This supersedes the earlier list-row and status-copy requirements only:

- Remove the MathJax rendering-status line from the visible UI.
- Remove `bank.status` (for example `ready`) from the selected-bank metadata line.
- Remove difficulty labels (`foundation`, `standard`, `challenge`) from question-list cards; difficulty may remain in the detail reader badge.
- Hovering a question card previews that item in the right reader immediately. Keyboard focus provides the same behavior, and click/touch plus previous/next navigation remain supported.
