# 相似三角形证明流程图

## 整体流程

```
开始相似证明
    ↓
步骤1：观察图形
    ↓
步骤2：寻找等角
    ↓
步骤3：选择判定方法
    ↓
步骤4：书写证明过程
    ↓
步骤5：验证结论
    ↓
结束
```

## 详细流程图

### 步骤1：观察图形
```
观察图形结构
    ↓
识别所有三角形
    ↓
找出可能的相似三角形对
    ↓
标记已知条件
```

### 步骤2：寻找等角
```
寻找等角
    ↓
检查公共角
    ↓
检查对顶角
    ↓
检查平行线性质（同位角、内错角）
    ↓
检查直角
    ↓
记录找到的等角
```

### 步骤3：选择判定方法
```
根据等角情况选择
    ↓
有两组角相等？ ——是——→ 使用AA判定法
    ↓ 否
有夹角和两边比例？ ——是——→ 使用SAS判定法
    ↓ 否
有三边比例？ ——是——→ 使用SSS判定法
    ↓ 否
重新检查图形，寻找其他条件
```

### 步骤4：书写证明过程
```
开始书写
    ↓
写“在△ABC和△ADE中”
    ↓
列出角相等条件，注明理由
    ↓
列出边比例条件（如需要）
    ↓
写“∴ △ABC ∼ △ADE”
    ↓
注明判定方法
```

### 步骤5：验证结论
```
检查证明过程
    ↓
条件是否充分？
    ↓
格式是否正确？
    ↓
结论是否合理？
    ↓
验证通过
```

## 判定方法选择流程图

```
开始选择判定方法
    ↓
有两组角相等？
    ↓
是 → 使用AA判定法
    ↓
否 → 有夹角和两边比例？
    ↓
是 → 使用SAS判定法
    ↓
否 → 有三边比例？
    ↓
是 → 使用SSS判定法
    ↓
否 → 重新检查图形
```

## 常见错误检查清单

### 证明前检查
- [ ] 是否找到了所有可能的等角？
- [ ] 是否选择了最合适的判定方法？
- [ ] 是否理解了每个条件的含义？

### 证明中检查
- [ ] 是否写清了“在△ABC和△ADE中”？
- [ ] 是否列出了所有必要的条件？
- [ ] 是否为每个条件注明了理由？
- [ ] 对应顶点顺序是否正确？

### 证明后检查
- [ ] 相似结论是否正确？
- [ ] 判定方法是否适用？
- [ ] 证明过程是否完整？

## 教学提示

### 给学生的建议
1. **不要急于下笔**：先观察图形，找到等角
2. **选择最简单的方法**：优先使用AA判定法
3. **规范书写**：按照标准格式书写证明
4. **仔细检查**：证明后检查是否有错误

### 给教师的建议
1. **示范完整过程**：先示范一个完整的证明
2. **强调步骤**：让学生掌握三步法
3. **提供变式练习**：不同图形，不同判定方法
4. **及时反馈**：批改时指出常见错误

## 实际应用示例

### 示例1：平行线中的相似
**图形：** 三角形ABC中，DE∥BC

**流程应用：**
1. 观察图形：△ADE和△ABC
2. 寻找等角：∠A=∠A（公共角），∠ADE=∠ABC（同位角）
3. 选择判定方法：AA（有两组角）
4. 书写证明：标准格式
5. 验证结论：△ADE∽△ABC

### 示例2：对顶角中的相似
**图形：** 两条直线相交形成对顶角

**流程应用：**
1. 观察图形：两个三角形有对顶角
2. 寻找等角：对顶角相等，加上另一组角
3. 选择判定方法：AA
4. 书写证明：标准格式
5. 验证结论：两个三角形相似

## 总结

相似三角形证明的关键是：
1. **先找角**：找到相等的角是基础
2. **再选法**：根据角的情况选择判定方法
3. **后写证**：规范书写证明过程

掌握这个流程，相似三角形证明就变得简单而系统。
