# 相似三角形视觉辅助材料

## 图形标记系统

### 1. 角标记
- **公共角**：用相同颜色或符号标记（如都标记为∠A）
- **对顶角**：用相同符号标记（如∠1和∠1'）
- **同位角**：用箭头或平行线符号标记
- **直角**：用直角符号标记（∟）

### 2. 边标记
- **相等边**：用相同数量的短线标记
- **成比例边**：用不同数量的短线标记（如1条、2条、3条）
- **平行边**：用箭头标记

### 3. 相似三角形标记
- **对应顶点**：用相同颜色或形状标记
- **相似符号**：在三角形旁标记∼符号
- **相似比**：标注相似比数值

## 颜色编码系统

### 推荐颜色方案
- **红色**：公共角、重要等角
- **蓝色**：对顶角、平行线性质角
- **绿色**：直角、特殊角
- **橙色**：成比例边
- **紫色**：相似三角形对应边

### 使用示例
```
△ABC ∼ △ADE
- ∠A（红色）：公共角
- ∠B（蓝色）= ∠D（蓝色）：同位角
- ∠C（绿色）= ∠E（绿色）：同位角
- AB/AD = AC/AE = BC/DE（橙色）：成比例边
```

## 动态演示建议

### 1. 相似变换演示
- **平移**：将一个三角形平移到另一个位置
- **旋转**：围绕对应点旋转
- **缩放**：按相似比放大或缩小
- **组合变换**：平移+旋转+缩放

### 2. 角相等演示
- **公共角**：显示两个三角形共享同一个角
- **对顶角**：显示两条直线相交形成的对顶角
- **平行线角**：显示平行线被截线所截形成的角

### 3. 边比例演示
- **动态测量**：实时显示边长变化
- **比例计算**：显示比例关系
- **比例尺**：显示相似比

## 互动学习活动

### 活动1：图形拼图
**材料：** 相似三角形卡片
**步骤：**
1. 学生分组，每组一套卡片
2. 找出相似的三角形对
3. 用颜色标记相等的角
4. 用线条标记成比例的边

### 活动2：角度追踪
**材料：** 透明三角形、彩色笔
**步骤：**
1. 在透明纸上画一个三角形
2. 用彩色笔标记各个角
3. 通过旋转、平移找到另一个三角形
4. 比较角的大小关系

### 活动3：比例计算器
**材料：** 尺子、计算器
**步骤：**
1. 测量三角形各边长度
2. 计算对应边的比例
3. 验证比例是否相等
4. 判断三角形是否相似
