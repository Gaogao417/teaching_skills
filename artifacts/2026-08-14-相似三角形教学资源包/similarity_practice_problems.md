# 相似三角形练习题集

## 基础篇：相似三角形识别

### 第1题：识别相似三角形
**图形：** 三角形ABC中，DE∥BC，D在AB上，E在AC上。

**要求：**
1. 找出图中的相似三角形对
2. 说明每对相似三角形的判定方法

**参考答案：**
- △ADE ∽ △ABC
- 判定方法：AA（∠A=∠A，∠ADE=∠ABC）

### 第2题：对顶角中的相似
**图形：** 两条直线相交于点O，形成△AOB和△COD。

**要求：**
1. 找出相等的角
2. 判断△AOB和△COD是否相似
3. 说明理由

**参考答案：**
- ∠AOB=∠COD（对顶角）
- 如果还有另一组角相等，则相似（AA判定法）

### 第3题：平行线中的相似
**图形：** 四边形ABCD中，AB∥CD，对角线AC和BD相交于点O。

**要求：**
1. 找出图中的相似三角形
2. 证明你的结论

**参考答案：**
- △AOB ∽ △COD
- 证明：AB∥CD → ∠OAB=∠OCD，∠OBA=∠ODC → AA判定法

## 进阶篇：相似三角形证明

### 第4题：基础证明题
**已知：** 在△ABC和△DEF中，∠A=∠D=90°，∠B=∠E。

**要求：** 证明△ABC ∽ △DEF

**参考证明：**
```
在△ABC和△DEF中，
∵ ∠A = ∠D = 90° （已知）
   ∠B = ∠E （已知）
∴ △ABC ∽ △DEF （AA判定法）
```

### 第5题：边比例证明
**已知：** 在△ABC和△DEF中，AB/DE=BC/EF=AC/DF。

**要求：** 证明△ABC ∽ △DEF

**参考证明：**
```
在△ABC和△DEF中，
∵ AB/DE = BC/EF = AC/DF （已知）
∴ △ABC ∽ △DEF （SSS判定法）
```

### 第6题：综合证明题
**已知：** 在四边形ABCD中，对角线AC和BD相交于点O，AO=2，OC=3，BO=4，OD=6。

**要求：**
1. 证明△AOB ∽ △COD
2. 求AB/CD的值

**参考答案：**
1. 证明：
```
在△AOB和△COD中，
∵ ∠AOB = ∠COD （对顶角相等）
   AO/CO = 2/3，BO/DO = 4/6 = 2/3
∴ △AOB ∽ △COD （SAS判定法）
```
2. AB/CD = AO/CO = 2/3

## 应用篇：相似三角形性质应用

### 第7题：求线段长度
**已知：** 在△ABC中，D是AB上一点，DE∥BC交AC于E，AD=2，DB=3，BC=5。

**要求：** 求DE的长度

**参考解答：**
因为DE∥BC，所以△ADE ∽ △ABC
根据相似性质：AD/AB = DE/BC
AB = AD + DB = 5
2/5 = DE/5
DE = 2

### 第8题：求比例关系
**已知：** 在△ABC中，D是BC上一点，AD是角平分线，AB=6，AC=8。

**要求：** 求BD/DC的值

**参考解答：**
根据角平分线定理：AB/AC = BD/DC
6/8 = BD/DC
BD/DC = 3/4

### 第9题：面积比问题
**已知：** △ABC ∽ △DEF，相似比为2:3。

**要求：** 求它们的面积比

**参考解答：**
相似三角形的面积比等于相似比的平方
面积比 = (2/3)² = 4/9

## 易错题集

### 易错题1：判定方法选择
**错误：** 有两组角相等却用SAS判定法
**正确：** 应使用AA判定法

### 易错题2：对应顶点顺序
**错误：** △ABC ∽ △AED（对应顶点不对应）
**正确：** △ABC ∽ △ADE（对应顶点对应）

### 易错题3：书写格式
**错误：** 直接写“△ABC ∽ △ADE”
**正确：** 写出完整证明过程

### 易错题4：比例计算
**错误：** 比例计算错误
**正确：** 仔细计算，验证结果

## 学习建议

### 1. 分阶段练习
**第一阶段：** 识别相似三角形（1-3题）
**第二阶段：** 书写证明过程（4-6题）
**第三阶段：** 应用性质解题（7-9题）
**第四阶段：** 综合挑战（10-12题）

### 2. 错题整理
- 记录每道错题
- 分析错误原因
- 总结改正方法
- 定期复习巩固

### 3. 方法总结
- 先找角，再选法，最后写证
- 优先使用AA判定法
- 注意对应顶点顺序
- 规范书写证明过程

通过系统的练习，学生可以逐步掌握相似三角形的识别、证明和应用，提高几何思维能力。
