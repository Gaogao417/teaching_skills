# 结构分析：二次函数一般式配方

## 原题
把二次函数一般式
\[
y=ax^2+bx+c\quad(a\ne0)
\]
配成顶点式，并按下列难度递进设置 5 道例题：
1. 首项系数为 1；
2. 首项系数不为 1；
3. \(\dfrac ba\) 不是偶数；
4. \(a,b\) 为分数；
5. \(a\) 为整数、\(b\) 含根号。

## 一、题目场景
- 数学对象：二次三项式、二次函数一般式与顶点式。
- 变量/参数：自变量 \(x\)，参数 \(a,b,c\)，且 \(a\ne0\)。
- 函数/图形：\(y=ax^2+bx+c\)，本讲义只训练代数配方，不要求画图。
- 已知条件：二次项、一次项、常数项均已给出。
- 要求目标：把一般式化为 \(y=a(x-h)^2+k\) 的形式。

## 二、核心结构
### 2.1 表层信息
- 表面考点：完全平方公式、提取公因式、分数与根式运算。
- 题型功能：`basic_skill`
- 是否值得完整 structural analysis：是；配方是二次函数顶点、对称轴、最值及二次方程方法的共同入口。
- 一句话问题模式：先提二次项系数，再把括号内写成 \(x^2+2mx\) 配方，最后拆中括号并合并常数。

### 2.2 结构表达
#### 判别条件表（概念辨析题用；不适用则写“无”）
无。

#### 情景量表（应用题用；不适用则写“无”）
无。

#### 命题网络（所有题型都写；简单题写简版）
- P1（题设）：\(y=ax^2+bx+c\)，且 \(a\ne0\)。
- P2（定义）：\(x^2+2mx=(x+m)^2-m^2\)。
- P3（计算状态）：\(y=a\left(x^2+\dfrac ba x\right)+c\)。
- P4（可推）：括号内一次项系数的一半为 \(\dfrac b{2a}\)。
- P5（目标）：\(y=a\left(x+\dfrac b{2a}\right)^2-\dfrac{b^2-4ac}{4a}\)。
- R1：P1 -> P3，方法：从二次项和一次项中提取 \(a\)。
- R2：P2 + P3 + P4 -> P5，方法：添上并减去 \(\left(\dfrac b{2a}\right)^2\)，再合并常数项。
- 目标：由 P5 得到顶点式，并可读出顶点与对称轴。

### 2.3 解题主链
```text
一般式 -> 提二次项系数 a -> 令括号内一次项系数等于 2m -> 配成 (x+m)^2-m^2 -> 拆中括号并合并 -> 顶点式
```

### 2.4 模型标签
- model_id：quadratic-completing-square
- model_name：二次函数一般式配方
- configuration：已知 \(a,b,c\)，要求化为 \(a(x-h)^2+k\)。
- 可迁移方向：读顶点和对称轴、求最值、解二次方程、推导求根公式。
- 非同构边界：只有一次式或缺少二次项时，不属于二次函数配方；\(a=0\) 时公式不可用。

## 二点五、知识点/模型锚点
- 建议讲义标题：配方：把一般式化成顶点式
- 知识点/模型名称：二次函数配方法。
- 核心公式/定理：
  \[
  \begin{aligned}
  y&=ax^2+bx+c\\
   &=a\left(x^2+\frac ba x\right)+c\\
   &=a\left[\left(x+\frac b{2a}\right)^2-\frac{b^2}{4a^2}\right]+c\\
   &=a\left(x+\frac b{2a}\right)^2-\frac{\Delta}{4a},\qquad \Delta=b^2-4ac.
  \end{aligned}
  \]
- 使用条件：\(a\ne0\)。
- 入口信号：看到 \(ax^2+bx+c\) 要化成顶点式，或需要求顶点、对称轴、最值。
- 易混边界：提取 \(a\) 时常数项通常留在括号外；半系数是 \(\dfrac b{2a}\)，不是 \(\dfrac b2\)；括号内减去的平方乘回时还要乘 \(a\)。
- 本题如何体现：五个系数组合只改变计算外观，核心动作保持不变。
- 可作为例题的结构层级：从整数半系数递进到分数、分式系数与根式系数。

## 三、关键转化
- 最关键的转化：把 \(x^2+\dfrac ba x\) 写成 \(x^2+2mx\)，由 \(2m=\dfrac ba\) 得 \(m=\dfrac b{2a}\)。
- 为什么降低计算量：统一得到一个完全平方，顶点式中的平移量和常数项直接显现。
- 不转化时的低效路径：反复展开猜测平方项，容易漏掉外面的 \(a\) 或把补入项符号写错。

## 四、标准路径骨架
1. 先做什么：从二次项和一次项中提取 \(a\)，使括号内 \(x^2\) 的系数为 1。
2. 再做什么：令括号内一次项系数 \(\dfrac ba=2m\)，求得 \(m=\dfrac b{2a}\)。
3. 建立什么关系：使用 \(x^2+2mx=(x+m)^2-m^2\)。
4. 如何求解：拆开 \(a[(x+m)^2-m^2]+c\)，再合并常数。
5. 需要检查什么：展开顶点式，确认二次项、一次项和常数项与原式一致。

## 四点五、标准完整解与验算
- 关键交点/关键量：不适用；关键量为半系数 \(\dfrac b{2a}\)。
- 面积/方程/关系式：\(x^2+2mx=(x+m)^2-m^2\)。
- 完整求解过程：
  \[
  \begin{aligned}
  ax^2+bx+c
  &=a\left(x^2+\frac ba x\right)+c\\
  &=a\left[\left(x+\frac b{2a}\right)^2-\left(\frac b{2a}\right)^2\right]+c\\
  &=a\left(x+\frac b{2a}\right)^2-\frac{b^2}{4a}+c\\
  &=a\left(x+\frac b{2a}\right)^2-\frac{b^2-4ac}{4a}.
  \end{aligned}
  \]
- 最终答案：\(y=a\left(x+\dfrac b{2a}\right)^2-\dfrac\Delta{4a}\)。
- 排除值：\(a=0\)。
- 退化情形：\(b=0\) 时无须补一次项，原式已是 \(ax^2+c\)。
- 验算：展开 \(a\left(x+\dfrac b{2a}\right)^2-\dfrac\Delta{4a}\)，可还原为 \(ax^2+bx+c\)。
- 本题最短可靠路径：提二次项系数 → 写成 \(x^2+2mx\) 并配方 → 拆中括号并合并。

## 五、出题人逻辑
- 诱导学生硬算的位置：分数和根式系数会让学生误以为方法改变。
- 真正的捷径：始终只盯括号内一次项系数，并取其一半。
- 训练的可迁移能力：在不同系数外观下稳定执行同一代数结构。

## 六、学生卡点预测
- 读题/入手动作卡点：不知道为何先提取 \(a\)，或只提二次项、不同时处理一次项。
- 建模/关系入口卡点：把 \(\dfrac ba\) 直接当作平方括号中的数，没有再除以 2。
- 求解/检查卡点：方括号内减去的项拿到外面时漏乘 \(a\)；负分数、根式平方计算出错。

## 七、变式原则
- 核心不变量：括号内首项系数为 1，且使用一次项系数的一半配方。
- 表层特征：整数、分数、根式及正负号。
- 可变维度：依次只改变 \(a\)、\(b/a\) 的整洁度、系数类型。
- 深化阶梯：首一整数 → 首项非一 → 半系数为分数 → 原系数为分数 → 一次项含根号。
- 允许的变换：改变 \(a,b,c\)，但每题只增加一种主要计算负担。
- 禁止的变换：同时加入复杂分式、双重根式和参数讨论，导致训练重点偏离配方动作。
- 表征切换：一般式与顶点式互化。
- 包装方式：可在后续改问顶点、对称轴或最值。
- 近迁移例子：把 \(2x^2+8x+5\) 改为 \(3x^2-12x+7\)。
- 远迁移例子：由配方结果直接判断函数最值。
- 反例/伪变式：只做大量复杂通分而不要求形成完全平方，不利于当前动作训练。

## 八、计算复杂度预算
- 原题计算层级：一步提取、一次平方、一次常数合并。
- 允许小步上升到：分母不超过 32；根式只含单个简单二次根式，平方后可化为整数。
- 禁止引入的计算负担：复合根式、有理化、多参数分类讨论。
- 必须保留的可见支架：每题都显式写出 \(2m=\) 括号内一次项系数。

## 九、推荐讲题任务包
- 建议的本轮教学入口：从 \(x^2+2mx=(x+m)^2-m^2\) 的统一结构进入。
- 本题讲解目标：学生能对任意 \(a\ne0\) 的二次三项式稳定完成配方。
- 不要直接讲的抽象话：不要只背“提、配、合”而没有对应的具体式子。
- 必须先问的问题：括号内 \(x\) 的系数是多少？它的一半是多少？
- 关键讲解顺序：首一整数 → 提取 \(a\) → 分数半系数 → 分数系数 → 根式系数。
- 最适合的具体数值例子：\(x^2+2x+4\)、\(2x^2+8x+5\)。
- 讲到哪里停下来让学生回答：每题写出提取 \(a\) 后，暂停让学生给出括号中平方项里的常数。

## 十、推荐练题任务包
- 若卡在读题/入手动作，出什么题：只要求圈出应该提取的 \(a\)，不继续计算。
- 若卡在建模或关系入口，出什么题：给 \(x^2+px\)，只填 \((x+\square)^2-\square\)。
- 若卡在求解和检查，出什么题：给出错误配方，让学生通过展开找错。
- 若原题已稳，如何小步迁移：改问顶点、对称轴与最值。
- 若结构识别已稳，如何深化/抽象/包装：推导 \(-\Delta/(4a)\) 并联系判别式。
- 禁止出的跑偏变式：复杂参数分类或需要新定理的综合题。
