# 结构分析：第 13 题两高相似计数

## 原题
如图，$AD,BE$ 是 $\triangle ABC$ 的两条高，$AD,BE$ 相交于点 $O$，问图中共有多少对相似三角形。

图形文字说明：$D$ 为 $AD$ 在 $BC$ 上的垂足，$E$ 为 $BE$ 在 $AC$ 上的垂足；重点标出相等的弧角 $\angle DBO$ 与 $\angle EAO$。

## 一、题目场景
- 数学对象：锐角三角形、两条高、两个垂足、垂心构型中的四个直角三角形。
- 变量/参数：无数值变量。
- 函数/图形：平面欧氏几何。
- 已知条件：$AD\perp BC$，$BE\perp AC$，交于 $O$。
- 要求目标：找全图中相似三角形并求相似对数。

## 二、核心结构
### 2.1 表层信息
- 表面考点：同角的余角相等、AA 相似、无重复配对计数。
- 题型功能：`concept_check`
- 是否值得完整 structural analysis：是；题目训练“标等角找对象”而非盲目枚举。
- 一句话问题模式：用同款弧角和直角筛出四个同角组三角形，再用握手模型数两两配对。

### 2.2 结构表达
#### 判别条件表（概念辨析题用；不适用则写“无”）
- 必要条件：候选三角形同时含一个同款弧角和一个直角。
- 充分条件：任意两个候选三角形都有一组弧角相等和一组直角相等，由 AA 相似。
- 常见干扰项：按大小、朝向猜相似；把同一对正反各数一次。
- 最短检查动作：先圈出四个“弧角 + 直角”三角形，再算每个三角形有 3 个伙伴。

#### 情景量表（应用题用；不适用则写“无”）
无。

#### 命题网络（所有题型都写；简单题写简版）
- P1（题设）：$AD\perp BC$，$BE\perp AC$，交于 $O$。
- P2（可推）：$\angle DBO=\angle EAO=90^\circ-\angle C$。
- P3（可推）：含弧角且含直角的三角形为 $\triangle BDO,\triangle BEC,\triangle AEO,\triangle ADC$。
- P4（可推）：四个三角形的角组均为 $90^\circ,\angle C,90^\circ-\angle C$，故两两相似。
- P5（计算状态）：每个三角形与另外 3 个相似，先得 $4\times3$ 次；每一对被正反重复计算 2 次。
- P6（目标）：相似三角形共有 $\dfrac{4\times3}{2}=6$ 对。
- R1：P1 -> P2，方法：同角的余角相等。
- R2：P1 + P2 -> P3，方法：按“弧角 + 直角”筛选。
- R3：P3 -> P4，方法：AA 判定相似。
- R4：P4 -> P5 -> P6，方法：握手式计数并除以 2 去重。
- 目标：标角、找四个、证两两相似、计数。

### 2.3 解题主链
```text
两条高 -> 标 ∠DBO 与 ∠EAO 为同款弧角
-> 找到四个“弧角+直角”三角形
-> 四个三角形两两相似
-> (4×3)÷2=6 对
```

### 2.4 模型标签
- model_id：`altitudes_equal_angle_similarity_handshake_count`
- model_name：两高构型标等角找全相似并握手计数。
- configuration：已知三角形两条高，求图中相似三角形对数。
- 可迁移方向：改变三角形形状、隐藏弧角、要求列出全部六对。
- 非同构边界：若两条线不是高，则四个候选三角形不统一为直角三角形。

## 二点五、知识点/模型锚点
- 建议讲义标题：标等角找相似，用“握手”数出 6 对。
- 知识点/模型名称：余角相等、AA 相似、无重复配对计数。
- 核心公式/定理：同角的余角相等；两角分别相等判定相似。
- 使用条件：相似式按“弧角—直角—剩余角”顺序书写。
- 入口信号：题面出现两条高并询问图中相似三角形对数。
- 易混边界：数的是相似“对数”，不是三角形个数；不使用排列组合术语。
- 本题如何体现：A 点一个弧角属于两个三角形，B 点一个弧角也属于两个三角形，共得到四个。
- 可作为例题的结构层级：相似识别与计数单题型。

## 三、关键转化
- 最关键的转化：把两条高转成 $\angle DBO=\angle EAO$，并把同款弧角作为视觉锚点。
- 为什么降低计算量：无需盲目枚举全图所有三角形。
- 不转化时的低效路径：逐个猜测三角形并重复证明，容易漏掉或重复。

## 四、标准路径骨架
1. 先做什么：由两条高标出 D、E 处直角。
2. 再做什么：证明并标出 $\angle DBO=\angle EAO$。
3. 建立什么关系：找到四个同时含弧角和直角的三角形。
4. 如何求解：由 AA 说明四个三角形两两相似；用 $4\times3\div2$ 计数。
5. 需要检查什么：正反顺序表示同一对，必须除以 2。

## 四点五、标准完整解与验算
- 关键交点/关键量：$D,E$ 为垂足，$O$ 为两高交点。
- 面积/方程/关系式：$\angle DBO=\angle EAO=90^\circ-\angle C$。
- 完整求解过程：由 $BE\perp AC$ 得 $\angle DBO=90^\circ-\angle C$；由 $AD\perp BC$ 得 $\angle EAO=90^\circ-\angle C$，故两角相等。含 B 点弧角的直角三角形为 $\triangle BDO,\triangle BEC$；含 A 点弧角的直角三角形为 $\triangle AEO,\triangle ADC$。四个三角形都含一个同款弧角和一个直角，因此两两相似。每个三角形有另外 3 个相似伙伴，先得 $4\times3$ 次；“A 与 B 相似”和“B 与 A 相似”是同一对，每对被数两次，所以共有 $\dfrac{4\times3}{2}=6$ 对。
- 最终答案：6 对。
- 排除值：无。
- 退化情形：默认原图为锐角三角形；直角三角形会使高与边重合，构型改变。
- 验算：六对为 $BDO-AEO,BDO-ADC,BDO-BEC,AEO-ADC,AEO-BEC,ADC-BEC$。
- 本题最短可靠路径：标等角——找四个——每个有 3 个伙伴——除以 2 去重。

## 五、出题人逻辑
- 诱导学生硬算的位置：复杂图中盲数三角形。
- 真正的捷径：用弧角与直角作为筛选器。
- 训练的可迁移能力：从垂直关系找等角；用对象—伙伴—去重解释配对数。

## 六、学生卡点预测
- 读题/入手动作卡点：不知道先标哪组等角。
- 建模/关系入口卡点：找到四个三角形却不会统一说明两两相似。
- 求解/检查卡点：把正反顺序各算一次，忘记除以 2。

## 七、变式原则
- 核心不变量：两条高产生四个同角组直角三角形。
- 表层特征：锐角三角形两条高。
- 可变维度：图形朝向、弧角是否预先标出、要求是否列出六对。
- 深化阶梯：原题复现；换图形朝向；隐藏弧角；要求列出全部六对。
- 允许的变换：改变锐角三角形形状并保持垂足在边上。
- 禁止的变换：把高改成中线仍套用四个直角三角形结论。
- 表征切换：图形标角与角组表。
- 包装方式：只给两条高，不提示弧角。
- 近迁移例子：换一个不等腰锐角三角形。
- 远迁移例子：圆或矩形中多组同角直角三角形的配对计数。
- 反例/伪变式：任意两条 cevian 相交而不垂直于对边。

## 八、计算复杂度预算
- 原题计算层级：角关系与小规模配对计数。
- 允许小步上升到：列出六对并核对对应顺序。
- 禁止引入的计算负担：排列组合符号、复杂角度数值、分类讨论。
- 必须保留的可见支架：同款弧角、两处直角、四个三角形清单和 $4\times3\div2$。

## 九、推荐讲题任务包
- 建议的本轮教学入口：先问“一个弧角分别属于哪两个直角三角形”。
- 本题讲解目标：学会通过标等角找相似，并用握手解释配对数。
- 不要直接讲的抽象话：不用排列组合或组合数。
- 必须先问的问题：哪四个三角形同时含弧角和直角？为什么 $4\times3$ 要除以 2？
- 关键讲解顺序：标弧角；找四个；两两相似；握手去重。
- 最适合的具体数值例子：本题无数值。
- 讲到哪里停下来让学生回答：找到四个三角形后，让学生解释除以 2。
