# 结构分析：第 17 题梯形三平行线三解

## 原题
如图，已知 $AB\parallel CD\parallel EF$，$AE:ED=3:2$，$AB=4$，$CD=9$，求 $EF$。

图形文字说明：四边形 $ABCD$ 为上底较短、下底较长的梯形，$E$ 在线段 $AD$ 上，$F$ 在线段 $BC$ 上，且 $EF$ 与两底平行。

## 一、题目场景
- 数学对象：梯形、三条平行线、内分点、相似三角形、平行四边形。
- 变量/参数：方法三设 $AE=3a$，$ED=2a$。
- 函数/图形：平面欧氏几何。
- 已知条件：$AB\parallel EF\parallel CD$，$AE:ED=3:2$，$AB=4$，$CD=9$。
- 要求目标：求中间平行线段 $EF$。

## 二、核心结构
### 2.1 表层信息
- 表面考点：A 字形相似、平行四边形、比例线段。
- 题型功能：`composite_problem`
- 是否值得完整 structural analysis：是；同一结果可以由“切分”“对角线分段”“延长成大三角形”三种构造得到，适合训练结构选择。
- 一句话问题模式：把梯形补成学生熟悉的 A 字形相似结构，再把 $EF$ 拆段或整体求出。

### 2.2 结构表达
#### 判别条件表（概念辨析题用；不适用则写“无”）
无。

#### 情景量表（应用题用；不适用则写“无”）
无。

#### 命题网络（所有题型都写；简单题写简版）
- P1（题设）：$AB\parallel EF\parallel CD$，$AB=4$，$CD=9$。
- P2（题设）：$E\in AD$，且 $AE:ED=3:2$，所以 $AE:AD=3:5$、$DE:DA=2:5$。
- P3a（构造）：过 $A$ 作 $AH\parallel BC$，交 $CD$ 于 $H$，交 $EF$ 于 $G$。
- P4a（可推）：$ABCH$、$ABFG$ 均为平行四边形，故 $DH=5$、$GF=4$。
- P5a（可推）：在 $\triangle ADH$ 中，$EG\parallel DH$，故 $EG=3$。
- P3b（构造）：连接 $BD$，交 $EF$ 于 $G$。
- P4b（可推）：在 $\triangle DAB$ 中，$EG/AB=DG/DB=2/5$，故 $EG=8/5$、$BG/BD=3/5$。
- P5b（可推）：在 $\triangle BCD$ 中，$GF/CD=BG/BD=3/5$，故 $GF=27/5$。
- P3c（构造）：延长 $DA,CB$ 交于 $P$，设 $AE=3a$、$ED=2a$。
- P4c（可推）：$\triangle PAB\sim\triangle PDC$，故 $PA/PD=4/9$；结合 $PD-PA=5a$ 得 $PA=4a$、$PD=9a$。
- P5c（可推）：$PE=7a$，且 $\triangle PEF\sim\triangle PAB$，故 $EF/AB=PE/PA=7/4$。
- P6（目标）：$EF=7$。
- R1a：P1 + P3a -> P4a，方法：两组对边分别平行判定平行四边形。
- R2a：P2 + P3a + P4a -> P5a，方法：A 字形相似。
- R3a：P4a + P5a -> P6，方法：线段和 $EF=EG+GF$。
- R1b：P1 + P2 + P3b -> P4b，方法：第一个 A 字形相似。
- R2b：P1 + P4b -> P5b，方法：第二个 A 字形相似。
- R3b：P4b + P5b -> P6，方法：线段和。
- R1c：P1 + P2 + P3c -> P4c，方法：第一个 A 字形相似与线段和差。
- R2c：P1 + P4c -> P5c -> P6，方法：第二个 A 字形相似。
- 目标：三条路线分别独立推出 P6；主路线为 R1a--R3a。

### 2.3 解题主链
```text
主方法：过 A 作 AH∥BC -> 平行四边形给出 DH=5、GF=4 -> △AEG∽△ADH 得 EG=3 -> EF=7
方法二：连接 BD -> 第一个 A 字形求 EG、BG/BD -> 第二个 A 字形求 GF -> EF=7
方法三：延长 DA、CB 交于 P -> 第一个 A 字形求 PA=4a -> 第二个 A 字形求 EF -> EF=7
```

### 2.4 模型标签
- model_id：`trapezoid_three_parallels_three_a_shape_methods`
- model_name：梯形三平行线段的三种 A 字形构造。
- configuration：已知上下底、腰上内分比，求与两底平行的截线长度。
- 可迁移方向：更换上下底和分点比；改问某一分段；要求比较三种辅助线。
- 非同构边界：若 $EF$ 不与两底平行，则三种相似比例均失效。

## 二点五、知识点/模型锚点
- 建议讲义标题：三条路线制造 A 字形，主方法先切出小三角形。
- 知识点/模型名称：A 字形相似、平行四边形分割、对角线双 A 字、延长腰双 A 字。
- 核心公式/定理：三角形中一边的平行线截另外两边，所得小三角形与原三角形相似；两组对边分别平行的四边形是平行四边形。
- 使用条件：比例必须沿同一条边保持同一方向；分段相加前确认点序。
- 入口信号：梯形中出现一条与两底平行的截线，同时给出腰上分点比。
- 易混边界：方法二中 $DG/DB=2/5$，所以 $BG/BD=3/5$；不能把两个比例写成同一个。
- 本题如何体现：三种构造都把原梯形改写成一个或两个标准 A 字形。
- 可作为例题的结构层级：相似三角形基础模型的多解法展示。

## 三、关键转化
- 最关键的转化：主方法过 $A$ 作 $AH\parallel BC$，把梯形切成一个平行四边形和一个小三角形。
- 为什么降低计算量：平行四边形直接搬运长度，只需在 $\triangle ADH$ 中写一次 A 字形比例。
- 不转化时的低效路径：直接设坐标或套“梯形截线线性变化”公式，虽能求值，但不训练本节的相似结构。

## 四、标准路径骨架
1. 先做什么：过 $A$ 作 $AH\parallel BC$，与 $CD,EF$ 分别交于 $H,G$。
2. 再做什么：用两个平行四边形得到 $DH=5$、$GF=4$。
3. 建立什么关系：在 $\triangle ADH$ 中用 $EG\parallel DH$ 得 $EG/DH=AE/AD=3/5$。
4. 如何求解：求得 $EG=3$，再算 $EF=EG+GF=7$。
5. 需要检查什么：确认 $E-G-F$ 的点序和 $D-H-C$ 的点序。

## 四点五、标准完整解与验算
- 关键交点/关键量：主方法中的 $H,G$；方法二中的 $G$；方法三中的 $P$。
- 面积/方程/关系式：$AE/AD=3/5$；方法三中 $PA/(PA+5a)=4/9$。
- 完整求解过程：主方法中，过 $A$ 作 $AH\parallel BC$，交 $CD$ 于 $H$，交 $EF$ 于 $G$。四边形 $ABCH$、$ABFG$ 为平行四边形，故 $HC=GF=AB=4$，$DH=CD-HC=5$。在 $\triangle ADH$ 中，$EG\parallel DH$，故 $EG/DH=AE/AD=3/5$，得 $EG=3$。于是 $EF=EG+GF=7$。方法二与方法三的完整关系见命题网络 P3b--P5c。
- 最终答案：$EF=7$。
- 排除值：无。
- 退化情形：题图为非退化梯形，$E,F$ 均在线段内部。
- 验算：截线长度按从 $AB$ 到 $CD$ 的比例 $3/5$ 线性变化，$EF=4+(9-4)\times3/5=7$，与三种几何解一致。
- 本题最短可靠路径：过 $A$ 作 $BC$ 的平行线，平行四边形搬长度后只用一次 A 字形。

## 五、出题人逻辑
- 诱导学生硬算的位置：看到三条平行线后同时追多个比例，或直接背梯形截线公式。
- 真正的捷径：构造平行四边形，把上下底之差 $9-4$ 变成小三角形的底。
- 训练的可迁移能力：选择辅助线，把陌生四边形问题转成熟悉的 A 字形。

## 六、学生卡点预测
- 读题/入手动作卡点：知道要用相似，却找不到三角形。
- 建模/关系入口卡点：主方法中看不出 $DH=CD-AB=5$；方法二中混淆 $DG/DB$ 与 $BG/BD$。
- 求解/检查卡点：多种方法写在一起，辅助点重名或比例串线。

## 七、变式原则
- 核心不变量：三条平行线、腰上内分比、上下底长度。
- 表层特征：上窄下宽梯形与水平截线。
- 可变维度：上下底数值、分点比、所求分段或整体。
- 深化阶梯：原题复现；同结构换数；改问 $EG$ 或 $GF$；不给辅助线；要求比较三种构造。
- 允许的变换：把 $3:2$ 换成正整数比，把 $4,9$ 换成便于整除的正数。
- 禁止的变换：去掉 $EF\parallel AB\parallel CD$，却仍要求沿用同一比例链。
- 表征切换：几何三解与线性插值验算。
- 包装方式：不直接给出 $E,F$ 同层，改成“过 $E$ 作两底的平行线交 $BC$ 于 $F$”。
- 近迁移例子：$AE:ED=2:1$，$AB=5$，$CD=11$。
- 远迁移例子：三角形被两条平行截线分成多个相似层级，求各层宽度。
- 反例/伪变式：只保留 $AB\parallel CD$，让 $EF$ 任意经过 $E$。

## 八、计算复杂度预算
- 原题计算层级：整数线段差、一次比例、简单分数加法。
- 允许小步上升到：分数底长或非整比例结果。
- 禁止引入的计算负担：坐标方程组、复杂根式、三角函数。
- 必须保留的可见支架：开头三分支流程图；三种方法各自独立成页；主方法的 $AH$、方法二的 $BD$、方法三的交点 $P$。

## 九、推荐讲题任务包
- 建议的本轮教学入口：先展示总流程图，再把主方法单独讲完。
- 本题讲解目标：把“过 $A$ 作 $BC$ 的平行线”固化成梯形截线题的优先动作，同时认识另外两种 A 字形构造。
- 不要直接讲的抽象话：不先讲线性插值公式，不把三条路线串成一个长解答。
- 必须先问的问题：过 $A$ 作 $BC$ 的平行线后，哪一块是平行四边形，哪一块是小三角形？
- 关键讲解顺序：总流程图；主方法；连接 $BD$ 的双 A 字；延长两腰的双 A 字。
- 最适合的具体数值例子：原题 $3:2,4,9$，使主方法得到 $DH=5$、$EG=3$。
- 讲到哪里停下来让学生回答：得到 $DH=5$ 后，让学生一笔写出 $EG=3$。

## 十、推荐练题任务包
- 若卡在读题/入手动作，出什么题：只要求画出过 $A$ 且平行于 $BC$ 的辅助线并圈出小三角形。
- 若卡在建模或关系入口，出什么题：给出辅助图，只填 $DH$、$EG$、$GF$。
- 若卡在求解和检查，出什么题：要求用连接对角线的方法完成两个比例。
- 若原题已稳，如何小步迁移：同结构换数，只用主方法。
- 若结构识别已稳，如何深化/抽象/包装：不给图，要求从三种构造中选最短路线并说明理由。
- 禁止出的跑偏变式：加入坐标、面积或角度条件导致主结构被遮蔽。
