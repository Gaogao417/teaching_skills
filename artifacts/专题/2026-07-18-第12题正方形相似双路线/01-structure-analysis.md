# 结构分析：第 12 题正方形相似双路线

## 原题
如图，在正方形 $ABCD$ 中，$E$ 为 $AB$ 边的中点，$G,F$ 分别为 $AD,BC$ 边上的点。若 $AG=2$，$BF=4$，$\angle GEF=90^\circ$，求 $GF$ 的长。

图形文字说明：正方形按 $A$ 左下、$B$ 右下、$C$ 右上、$D$ 左上放置；$G$ 在 $AD$ 上，$F$ 在 $BC$ 上；连接 $GE,EF,GF$。

## 一、题目场景
- 数学对象：正方形、边中点、两个边上点、三个直角三角形与梯形 $ABFG$。
- 变量/参数：设 $AE=BE=x$。
- 函数/图形：平面欧氏几何。
- 已知条件：正方形、中点、$AG=2$、$BF=4$、$GE\perp EF$。
- 要求目标：求 $GF$。

## 二、核心结构
### 2.1 表层信息
- 表面考点：AA 相似、对应边成比例、勾股定理、梯形添高。
- 题型功能：`composite_problem`
- 是否值得完整 structural analysis：是；本题有一个公共相似阶段和两条并列的勾股收尾路线。
- 一句话问题模式：先把垂直关系转成相似以确定正方形尺度，再任选一种直角三角形收尾。

### 2.2 结构表达
#### 判别条件表（概念辨析题用；不适用则写“无”）
无。

#### 情景量表（应用题用；不适用则写“无”）
无。

#### 命题网络（所有题型都写；简单题写简版）
- P1（题设）：$ABCD$ 为正方形，$E$ 为 $AB$ 中点，$AG=2$，$BF=4$。
- P2（题设）：$GE\perp EF$。
- P3（可推）：$\angle GAE=\angle EBF=90^\circ$，且 $\angle AGE=\angle BEF$。
- P4（可推）：$\triangle AGE\sim\triangle BEF$。
- P5（计算状态）：设 $AE=BE=x$，则 $\dfrac2x=\dfrac x4$。
- P6（可推）：$AE=BE=2\sqrt2$，$AB=4\sqrt2$。
- P7a（可推）：$GE=2\sqrt3$，$EF=2\sqrt6$。
- P7b（构造）：过 $G$ 作 $GH\perp BF$ 于 $H$，则 $GH=4\sqrt2$，$HF=2$。
- P8（目标）：$GF=6$。
- R1：P1 + P2 -> P3，方法：两组垂线所成锐角相等。
- R2：P3 -> P4，方法：AA 判定相似。
- R3：P1 + P4 -> P5 -> P6，方法：对应边成比例与中点条件。
- R4a：P6 -> P7a -> P8，方法：分别解两个直角三角形后在 $\triangle GEF$ 中勾股。
- R4b：P6 + P7b -> P8，方法：梯形添高后在 $\triangle GHF$ 中勾股。
- 目标：公共阶段走 R1--R3；收尾路线从 R4a、R4b 中任选其一。

### 2.3 解题主链
```text
公共阶段：垂直关系 -> 等角 -> △AGE∽△BEF -> AE=BE=2√2 -> AB=4√2
方法一：求 GE、EF -> 在 △GEF 中勾股 -> GF=6
方法二：作 GH⊥BF -> 求 GH、HF -> 在 △GHF 中勾股 -> GF=6
```

### 2.4 模型标签
- model_id：`square_perpendicular_similarity_two_finishes`
- model_name：正方形垂直转相似后双路线求边。
- configuration：已知两侧边段、中点及 $GE\perp EF$，求跨边线段 $GF$。
- 可迁移方向：更换 $AG,BF$；改问正方形边长、$GE$ 或 $EF$；比较两条收尾路线。
- 非同构边界：去掉中点条件后不能用同一个未知量表示 $AE,BE$。

## 二点五、知识点/模型锚点
- 建议讲义标题：先相似定尺度，再用两种方法求 $GF$。
- 知识点/模型名称：垂直转等角、AA 相似、对应边比例、勾股定理、梯形添高。
- 核心公式/定理：两角分别相等判定相似；相似三角形对应边成比例；$a^2+b^2=c^2$。
- 使用条件：相似顺序按 $A\leftrightarrow B,G\leftrightarrow E,E\leftrightarrow F$；勾股前确认直角位置。
- 入口信号：正方形带来两组直角，$GE\perp EF$ 带来一组可转移的锐角。
- 易混边界：方法一与方法二是并列收尾，不能写成前后连续步骤。
- 本题如何体现：公共阶段只负责确定尺度；两种方法都从 $AB=4\sqrt2$ 出发独立求 $GF$。
- 可作为例题的结构层级：相似综合单题型。

## 三、关键转化
- 最关键的转化：把 $GE\perp EF$ 与正方形边的垂直关系转成 $\angle AGE=\angle BEF$。
- 为什么降低计算量：先用相似直接得到正方形边长，不必设坐标列点积方程。
- 不转化时的低效路径：坐标法虽可求解，但弱化了相似对应与辅助线训练。

## 四、标准路径骨架
1. 先做什么：标出 $A,B,E$ 处相关直角。
2. 再做什么：证明 $\triangle AGE\sim\triangle BEF$。
3. 建立什么关系：设 $AE=BE=x$，列 $2/x=x/4$。
4. 如何求解：得 $x=2\sqrt2$、$AB=4\sqrt2$；再选择方法一或方法二。
5. 需要检查什么：长度只取正根；两种方法不能串成一条路线。

## 四点五、标准完整解与验算
- 关键交点/关键量：$AE=BE=x$；方法二新增垂足 $H$。
- 面积/方程/关系式：$\dfrac{AG}{BE}=\dfrac{AE}{BF}$。
- 完整求解过程：由 $AG\perp AE$、$BE\perp BF$、$GE\perp EF$，得 $\angle AGE=\angle BEF$，故 $\triangle AGE\sim\triangle BEF$。设 $AE=BE=x$，由 $2/x=x/4$ 得 $x=2\sqrt2$，所以 $AB=4\sqrt2$。方法一：$GE=2\sqrt3$，$EF=2\sqrt6$，故 $GF=\sqrt{12+24}=6$。方法二：作 $GH\perp BF$，则 $ABHG$ 为矩形，$GH=4\sqrt2$，$HF=2$，故 $GF=\sqrt{32+4}=6$。
- 最终答案：$GF=6$。
- 排除值：$x$ 为长度，只取正根。
- 退化情形：题设点均在边上，无退化。
- 验算：取 $A(0,0),B(4\sqrt2,0),G(0,2),F(4\sqrt2,4)$，则 $GF^2=32+4=36$。
- 本题最短可靠路径：相似求 $AB$ 后作 $GH$，一次勾股；教学中并列展示方法一。

## 五、出题人逻辑
- 诱导学生硬算的位置：直接设正方形边长或坐标。
- 真正的捷径：先相似确定尺度，再按已有直角或新作高线收尾。
- 训练的可迁移能力：识别公共阶段与并列分支，避免把两种方法混写。

## 六、学生卡点预测
- 读题/入手动作卡点：看不出两组垂直产生等角。
- 建模/关系入口卡点：相似对应边写反。
- 求解/检查卡点：两种收尾路线混在一起；忘记长度取正根。

## 七、变式原则
- 核心不变量：垂直转等角，相似确定尺度，直角三角形收尾。
- 表层特征：正方形、边中点、两侧边上点。
- 可变维度：$AG,BF$ 的数值或所求边。
- 深化阶梯：原题复现；同结构换数；改问正方形边长；隐藏辅助线；比较两种方法。
- 允许的变换：更换为能得到干净根式的正数。
- 禁止的变换：同时去掉中点和垂直条件。
- 表征切换：几何解与坐标验算。
- 包装方式：不提示相似三角形名称或不提示 $GH$。
- 近迁移例子：换 $AG=3,BF=12$。
- 远迁移例子：矩形内两条垂直折线确定跨边距离。
- 反例/伪变式：$E$ 不是中点却仍令 $AE=BE$。

## 八、计算复杂度预算
- 原题计算层级：一元二次比例式取正根与勾股根式化简。
- 允许小步上升到：干净根式与两种路线比较。
- 禁止引入的计算负担：复杂二次方程、三角函数、多层分类。
- 必须保留的可见支架：公共阶段与两条分支的横排流程；方法二的虚线辅助线 $GH$。

## 九、推荐讲题任务包
- 建议的本轮教学入口：先问“哪两个直角三角形相似”。
- 本题讲解目标：掌握“公共相似阶段 + 两种独立勾股收尾”。
- 不要直接讲的抽象话：不要把两种方法顺次写成一条长路线。
- 必须先问的问题：相似对应顺序是什么？公共阶段结束时得到了哪些量？
- 关键讲解顺序：阶段 a 相似求 $AE,BE$；方法一与方法二分开呈现。
- 最适合的具体数值例子：原题 $2,4$。
- 讲到哪里停下来让学生回答：求得 $AB=4\sqrt2$ 后，让学生选择收尾入口。
