# 结构分析：线段与锐角三角比的双向互求

## 原题

统一构型：在 $\mathrm{Rt}\triangle ABC$ 中，$\angle B=90^\circ$，以锐角 $\angle C$ 为参照角。

- 方向一（线段 $\to$ 三角比）：已知两条边，必要时先用勾股定理补边，再求 $\sin C$、$\cos C$、$\tan C$ 或 $\cot C$。
- 方向二（三角比 $\to$ 线段）：已知 $\angle C$ 的一个三角比和一条边，先还原三边份数比，再用同倍缩放求目标边。

练习共 15 题：前 5 题使用训练数库中审核后可用的常见整数勾股数；后 10 题使用同一数库中基于常见勾股数的简单分数倍数据。

## 一、题目场景

- 数学对象：直角三角形、锐角 $C$、对边 $AB$、邻边 $BC$、斜边 $AC$。
- 变量/参数：三条边长以及 $\angle C$ 的正弦、余弦、正切、余切。
- 函数/图形：固定为 $\angle B=90^\circ$ 的直角三角形 $ABC$。
- 已知条件：两边，或一个三角比与一条边；边长均为正。
- 要求目标：在“线段数据”和“三角比数据”之间双向转换。

## 二、核心结构

### 2.1 表层信息

- 表面考点：锐角三角比定义、勾股定理、比例缩放、分数运算。
- 题型功能：`basic_skill`
- 是否值得完整 structural analysis：是；该题型是解直角三角形的基础反应链，重点不是单道计算，而是稳定的双向流程。
- 一句话问题模式：先把 $\angle C$ 的三条边固定成“对 $AB$、邻 $BC$、斜 $AC$”，再判断是列比还是按份数缩放。

### 2.2 结构表达

#### 判别条件表

| 已知与所求 | 第一动作 | 主关系 |
|---|---|---|
| 已知两边，求三角比 | 定位对、邻、斜；缺边才勾股 | $\sin C=AB/AC$，$\cos C=BC/AC$，$\tan C=AB/BC$，$\cot C=BC/AB$ |
| 已知三角比和一边，求另一边 | 把三角比还原成三边份数 | 份数边 $\times$ 同一倍数 $k$ |

- 必要条件：在直角三角形中，参照角为锐角 $C$，三边长均为正。
- 充分条件：已知量足以确定目标边或目标比。
- 常见干扰项：把 $BC$ 错认成对边；把正切的分子分母写反；已知三角比后直接交叉相乘却没有先说明对应边；已知两边时机械补齐所有边。
- 最短检查动作：在草稿上先写“对 $AB$、邻 $BC$、斜 $AC$”。

#### 情景量表

无。

#### 命题网络

- P1（题设）：$\angle B=90^\circ$，参照角为 $\angle C$。
- P2（定义）：相对 $\angle C$，$AB$ 是对边，$BC$ 是邻边，$AC$ 是斜边。
- P3（题设）：给出两条边，或给出一个三角比和一条边。
- P4（计算状态）：若三角比给出 $a/c$、$b/c$ 或 $a/b$，可还原一个整数勾股数组 $a:b:c$。
- P5（计算状态）：用已知边确定统一倍数 $k$，三边同乘 $k$。
- P6（目标）：得到目标边或化简后的目标三角比。
- R1：P1 + P2 -> 三角比公式，方法：锐角三角比定义。
- R2：P2 + P3 -> P6，方法：必要时勾股补边后列比。
- R3：P3 + P4 -> P5，方法：从三角比还原份数并由已知边定倍数。
- R4：P5 + P2 -> P6，方法：三边同比例缩放。
- 目标：根据题面方向选择 R2 或 R3+R4。

### 2.3 解题主链

```text
先写：对 AB、邻 BC、斜 AC
├─ 已知边求三角比：看函数名 -> 只找所需两边 -> 缺边才勾股 -> 列比化简
└─ 已知三角比求边：读成边比 -> 补成三边份数 -> 已知边定倍数 -> 同倍求目标边
```

### 2.4 模型标签

- model_id：right_triangle_segment_ratio_bidirectional
- model_name：直角三角形线段—三角比双向翻译
- configuration：$\angle B=90^\circ$，参照角固定为 $C$；已知边或一个三角比，求另一侧表示。
- 可迁移方向：更换函数名、交换已知与所求、整数勾股数组整体乘整数或简单分数。
- 非同构边界：一般三角形中直接使用对邻斜；反三角函数求角；引入正弦定理或余弦定理。

## 二点五、知识点/模型锚点

- 建议讲义标题：线段 $\Longleftrightarrow$ 三角比：一张图走通双向流程
- 知识点/模型名称：对邻斜定位、定义列比、勾股补边、份数缩放。
- 核心公式/定理：$\sin C=AB/AC$，$\cos C=BC/AC$，$\tan C=AB/BC$，$\cot C=BC/AB$；$AB^2+BC^2=AC^2$。
- 使用条件：$\triangle ABC$ 为直角三角形且 $\angle C$ 为锐角。
- 入口信号：题目在边长和 $\angle C$ 的三角比之间互求。
- 易混边界：对边、邻边会随参照角改变；斜边只由直角决定。本讲固定参照角 $C$，先练稳定流程。
- 本题如何体现：一个例题从 $\sin C=3/5$ 与 $BC=8$ 求 $AC$；另一个例题从 $AB=5,BC=12$ 求 $\sin C$。
- 可作为例题的结构层级：双向基础模型 + 分数缩放迁移。

## 三、关键转化

- 最关键的转化：把三角比看成“边长份数比”，而不是孤立分数。
- 为什么降低计算量：一旦识别 $3:4:5$、$5:12:13$ 等勾股数组，求边只需一次同倍缩放，不必同时列多个方程。
- 不转化时的低效路径：每题都机械设未知数、交叉相乘、再单独做勾股，步骤长且容易对应错边。

## 四、标准路径骨架

1. 先做什么：写出相对 $\angle C$ 的“对 $AB$、邻 $BC$、斜 $AC$”。
2. 再做什么：判断题目是“边求比”还是“比求边”。
3. 建立什么关系：边求比用定义；比求边把分数还原成边的份数比。
4. 如何求解：缺必要边才勾股；已知三角比则用已知边确定同倍缩放系数。
5. 需要检查什么：分子分母是否对应正确；斜边是否最长；三边是否满足勾股；$0<\sin C,\cos C<1$。

## 四点五、标准完整解与验算

- 关键交点/关键量：无；关键是三边角色固定。
- 面积/方程/关系式：$AB^2+BC^2=AC^2$，四个三角比定义。
- 完整求解过程：例 1，$\sin C=3/5$ 表示 $AB:AC=3:5$，由勾股数组得 $AB:BC:AC=3:4:5$。已知 $BC=8=4\times2$，故 $AC=5\times2=10$。例 2，$AB=5,BC=12$，由勾股得 $AC=13$，所以 $\sin C=AB/AC=5/13$。
- 最终答案：例 1 为 $AC=10$；例 2 为 $\sin C=5/13$。
- 排除值：边长和缩放倍数均为正。
- 退化情形：任何边长为 $0$ 均不允许。
- 验算：例 1 有 $6^2+8^2=10^2$；例 2 有 $5^2+12^2=13^2$，且 $5/13<1$。
- 本题最短可靠路径：定边角色 -> 选方向 -> 定义或份数 -> 缩放/勾股 -> 检查。

## 五、出题人逻辑

- 诱导学生硬算的位置：看到分数便直接交叉相乘，忘记这个分数对应哪两条边。
- 真正的捷径：先把分数翻译成勾股数组的两条对应边，再由已知边确定统一倍数。
- 训练的可迁移能力：在线段表示和三角比表示之间快速、可逆地翻译。

## 六、学生卡点预测

- 读题/入手动作卡点：不能稳定说出相对 $\angle C$ 的对边、邻边、斜边。
- 建模/关系入口卡点：不知道 $3/5$ 是哪两条边的份数比，或不能补出第三边份数 $4$。
- 求解/检查卡点：只缩放一条边；分数边运算后不化简；忘记检查斜边最长。

## 七、变式原则

- 核心不变量：三边角色与三角比定义不变；相似直角三角形的三边只做同倍缩放。
- 表层特征：函数名、已知边、目标边、勾股数组、缩放系数。
- 可变维度：每题只更换一个主方向或一种已知边位置。
- 深化阶梯：整数边直接列比 -> 已知三角比反求边 -> 已知斜边定倍数 -> 简单分数缩放 -> 问法轻微反转。
- 允许的变换：使用数库中审核后可用的 $3$-$4$-$5$、$5$-$12$-$13$、$7$-$24$-$25$、$8$-$15$-$17$ 及其简单分数倍。
- 禁止的变换：整数勾股数组整体乘根式；同时隐藏参照角并提高分数复杂度；引入一般三角形定理。
- 表征切换：给边求比、给比求边、给斜边定倍数、给直角边定倍数。
- 包装方式：不直接说“这是某个勾股数组”，要求学生从分数识别份数。
- 近迁移例子：$\cos C=12/13$ 且 $AC=13/2$，求 $AB$。
- 远迁移例子：给 $\tan C$ 和斜边，先补齐份数再求两直角边。
- 反例/伪变式：只更换点名却把参照角从 $C$ 改为 $A$；这会同时改变所有边角色，不适合本轮基础训练。

## 八、计算复杂度预算

- 原题计算层级：一次认边，一次勾股或一次同倍缩放，一次约分。
- 允许小步上升到：分母不超过 $7$ 的简单分数边，且最终答案仍为小整数或简单分数。
- 禁止引入的计算负担：复杂根式、有理化、反三角函数、多层方程组。
- 必须保留的可见支架：统一构型与“对 $AB$、邻 $BC$、斜 $AC$”口令；教师版保留数库来源。

## 九、推荐讲题任务包

- 建议的本轮教学入口：先在统一图上让学生连续指出 $AB,BC,AC$ 的角色。
- 本题讲解目标：形成两条标准流程，并知道何时用勾股、何时用份数缩放。
- 不要直接讲的抽象话：不扩展到单位圆、三角函数图像或一般三角形。
- 必须先问的问题：“这个三角比的分子和分母分别是哪条边？”
- 关键讲解顺序：固定边角色 -> 边求比 -> 比求边 -> 双向对照。
- 最适合的具体数值例子：$3$-$4$-$5$ 和 $5$-$12$-$13$。
- 讲到哪里停下来让学生回答：三角比还原成两条边份数后，停下来让学生补第三边份数。

## 十、推荐练题任务包

- 若卡在读题/入手动作，出什么题：只问四种三角比对应哪两条边。
- 若卡在建模或关系入口，出什么题：给 $3/5$、$4/5$、$3/4$，要求口答对应边份数。
- 若卡在求解和检查，出什么题：给一条边定倍数，要求补全三边并验算。
- 若原题已稳，如何小步迁移：改为数库中的简单分数倍三边。
- 若结构识别已稳，如何深化/抽象/包装：交替出现“边求比”和“比求边”，不给方向提示。
- 禁止出的跑偏变式：一般三角形解法、反求角、复杂根式缩放。

## 十点五、推荐图形请求包（可选）

- 是否需要图：是；讲义用一幅统一构型图锁定三边角色。练习沿用同一文字约定，不重复 15 幅同构图。
- 图形类型：`synthetic_geometry`
- 用图意图：`student_explanation`
- 需要出现的对象：$A,B,C$，三边 $AB,BC,AC$，$B$ 点直角标记。
- 需要突出给学生看的关系：$\angle C$ 是参照角；$AB$、$BC$、$AC$ 分别是对边、邻边、斜边（角色在讲解文字中说明，clean 图不预写答案）。
- 图中不能暗示的错误性质：不要画成等腰；不要添加边长或答案；不要把直角画在其他点。
- 图失败时的降级方案：停止讲义图生成，不用破图占位。
