# 结构分析：第14题共角相似的两种对应

## 原题
如图，点 $D$ 在 $\triangle ABC$ 的边 $AB$ 上，$AD=2$，$AB=9$，$AC=6$。过点 $D$ 的直线交 $AC$ 于点 $E$，使以点 $A,D,E$ 为顶点的三角形与 $\triangle ABC$ 相似，求 $AE$。

## 一、题目场景
- 数学对象：共用顶点 $A$ 的小三角形 $\triangle ADE$ 与大三角形 $\triangle ABC$。
- 变量/参数：$AE$。
- 函数/图形：三角形、边上点、相似三角形。
- 已知条件：$D\in AB$，$E\in AC$，$AD=2$，$AB=9$，$AC=6$，$\triangle ADE$ 与 $\triangle ABC$ 相似。
- 要求目标：求所有可能的 $AE$。

## 二、核心结构
### 2.1 表层信息
- 表面考点：相似三角形对应边成比例。
- 题型功能：`existence_or_parameter`。
- 是否值得完整 structural analysis：是；相似关系没有给出顶点顺序，需要分类对应。
- 一句话问题模式：两个三角形共用一个角，先锁定共角的对应顶点，再交换其余两个顶点得到两种比例。

### 2.2 结构表达
#### 判别条件表（概念辨析题用；不适用则写“无”）
无。

#### 情景量表（应用题用；不适用则写“无”）
无。

#### 命题网络
- P1（题设）：$D\in AB$，$E\in AC$，所以射线 $AD$ 与 $AB$ 重合，射线 $AE$ 与 $AC$ 重合。
- P2（可推）：$\angle DAE=\angle BAC$，故相似对应中 $A\leftrightarrow A$。
- P3（题设）：$AD=2$，$AB=9$，$AC=6$。
- P4（分支一）：$\triangle ADE\sim\triangle ABC$。
- P5（分支二）：$\triangle AED\sim\triangle ABC$。
- P6（目标）：求两种对应下的 $AE$ 并检查位置。
- R1：P1 -> P2，方法：共线射线确定共同角。
- R2：P2 + P4 + P3 -> $AD/AE=AB/AC$，方法：按对应顶点写对应边比例。
- R3：P2 + P5 + P3 -> $AE/AD=AB/AC$，方法：交换其余两个对应顶点。
- 目标：由 R2、R3 分别求值，再检验 $0<AE<AC$。

### 2.3 解题主链
```text
共角 A 固定对应 -> 其余两点有两种对应 -> 写两种对应边比例 -> 求 AE -> 位置检验
```

### 2.4 模型标签
- model_id：`similarity_shared_angle_two_vertex_maps`
- model_name：共角相似的两种顶点对应
- configuration：已知两三角形相似但未给对应顺序，共角已知，求共角两边上的分点长度。
- 可迁移方向：换数、换边、把所求改为另一条分点线段。
- 非同构边界：若题目已按顺序写明 $\triangle ADE\sim\triangle ABC$，则对应唯一，不再分类。

## 二点五、知识点/模型锚点
- 建议讲义标题：共角先固定，另外两点分两种对应。
- 知识点/模型名称：相似三角形的顶点对应与分类。
- 核心公式/定理：对应边成比例；本题两式为 $AD/AE=AB/AC$ 或 $AE/AD=AB/AC$。
- 使用条件：只知道“两个三角形相似”，但没有给出相似顶点顺序。
- 入口信号：两个三角形共用同一顶点，且两组边分别共线。
- 易混边界：相似不是只有一种对应；比例式中的分子、分母必须按同一顶点顺序。
- 本题如何体现：$A$ 对应 $A$ 后，$D,E$ 可分别对应 $B,C$，也可分别对应 $C,B$。
- 可作为例题的结构层级：共角明显、两分支均合法的基础分类题。

## 三、关键转化
- 最关键的转化：先用 $\angle DAE=\angle BAC$ 固定 $A\leftrightarrow A$，再只讨论其余两点的交换。
- 为什么降低计算量：不用猜整套相似顺序，只剩两个分支。
- 不转化时的低效路径：随意写比例，容易漏解或把不对应的边放在同一比中。

## 四、标准路径骨架
1. 找到共同角 $\angle DAE=\angle BAC$。
2. 固定 $A\leftrightarrow A$。
3. 分别列出 $D\leftrightarrow B,E\leftrightarrow C$ 与 $D\leftrightarrow C,E\leftrightarrow B$。
4. 写对应边比例并求出两个 $AE$。
5. 检查两个值是否都满足 $0<AE<6$。

## 四点五、标准完整解与验算
- 关键交点/关键量：$E\in AC$，$AE$ 为未知量。
- 面积/方程/关系式：$AD/AE=AB/AC$ 或 $AE/AD=AB/AC$。
- 完整求解过程：
  - 因为 $D\in AB$、$E\in AC$，所以 $\angle DAE=\angle BAC$，从而 $A\leftrightarrow A$。
  - 若 $\triangle ADE\sim\triangle ABC$，则 $2/AE=9/6$，解得 $AE=4/3$。
  - 若 $\triangle AED\sim\triangle ABC$，则 $AE/2=9/6$，解得 $AE=3$。
- 最终答案：$AE=\dfrac43$ 或 $3$。
- 排除值：无；两值都为正且小于 $6$。
- 退化情形：$E$ 不与 $A,C$ 重合；两解均不退化。
- 验算：$\frac{2}{4/3}=\frac96=\frac32$；$\frac32=\frac96$。
- 本题最短可靠路径：共角固定对应点，再交换另外两个对应点。

## 五、出题人逻辑
- 诱导学生硬算的位置：看到“相似”就直接写唯一比例。
- 真正的捷径：共同角先锁定一个顶点，剩余两点恰有两种对应。
- 训练的可迁移能力：从角的对应关系反推边的对应关系，并完整分类。

## 六、学生卡点预测
- 读题/入手动作卡点：没有先找 $\angle DAE=\angle BAC$。
- 建模/关系入口卡点：固定 $A$ 后仍只写一种 $D,E$ 对应。
- 求解/检查卡点：比例上下顺序不一致，或求出两值后误删其中一个。

## 七、变式原则
- 核心不变量：共角固定一个顶点，另外两点存在两种对应。
- 表层特征：三角形内两边上各有一个点。
- 可变维度：只换 $AD,AB,AC$ 的数值，或改求 $AD/AE$。
- 深化阶梯：明显共角 -> 隐藏共角 -> 给出一组角相等但不标顶点顺序。
- 允许的变换：交换大三角形两邻边长度；把 D、E 改到延长线上并增加位置检验。
- 禁止的变换：直接给出有序相似式后仍要求两类。
- 表征切换：从图形语言切换为顶点对应表。
- 包装方式：题干只说“两三角形相似”，不写相似符号顺序。
- 近迁移例子：$AD=3,AB=12,AC=8$，同样求 $AE$。
- 远迁移例子：两个共顶点的相似四边形中确定对应边。
- 反例/伪变式：若明确写 $\triangle ADE\sim\triangle ABC$，则只能取 $D\leftrightarrow B,E\leftrightarrow C$。

## 八、计算复杂度预算
- 原题计算层级：两个一次比例方程。
- 允许小步上升到：出现简单分数或需要一次位置检验。
- 禁止引入的计算负担：根式、三角函数、复杂证明。
- 必须保留的可见支架：共同角和两张顶点对应表。

## 九、推荐讲题任务包
- 建议的本轮教学入口：先问“两个三角形哪一个角一定对应？”
- 本题讲解目标：会从共角锁定顶点，并完整写出两种对应比例。
- 不要直接讲的抽象话：不要先讲排列组合或六种相似顺序。
- 必须先问的问题：为什么 $A$ 必须对应 $A$？
- 关键讲解顺序：找共角 -> 固定 A -> 交换 D、E 的对应 -> 写比例 -> 检验。
- 最适合的具体数值例子：原题 $2,9,6$，两解干净且都在线段内。
- 讲到哪里停下来让学生回答：写出第一种对应后，问“D、E 交换对应还能不能成立？”

## 十、推荐练题任务包
- 若卡在读题/入手动作，出什么题：只要求圈出两个三角形的共同角。
- 若卡在建模或关系入口，出什么题：给对应顶点表，选择正确比例式。
- 若卡在求解和检查，出什么题：两个候选值中一个落在线段外，需要排除。
- 若原题已稳，如何小步迁移：同结构换数。
- 若结构识别已稳，如何深化/抽象/包装：把共角藏在共线或对顶角中。
- 禁止出的跑偏变式：引入全等、三角函数或复杂辅助线。
