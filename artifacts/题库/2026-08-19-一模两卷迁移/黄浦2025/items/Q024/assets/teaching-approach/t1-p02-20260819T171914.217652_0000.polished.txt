我们来逐步解决这道平行四边形中的动点问题。请按以下步骤操作：先看图形结构，再找关键辅助线和数量关系，然后计算所求线段或比值。

首先，观察已知条件：平行四边形 $ABCD$ 中，$AB=9$，$BC=5$，$\sin B=\frac{4}{5}$；点 $P$ 在边 $AB$ 上运动；过点 $P$ 作 $PE\perp PC$，交射线 $CD$ 于点 $E$，交对角线 $AC$ 于点 $H$；点 $F$ 在线段 $PE$ 上，且满足 $\frac{FP}{PC}=\frac{2}{3}$；最后联结 $CF$。

**第（1）问：求证 $\angle BAC = \angle PCF$**

第一步：作辅助线。过点 $C$ 作 $CG \perp AB$，垂足为点 $G$。  
第二步：在 $\triangle BCG$ 中，已知 $BC = 5$，$\sin B = \frac{4}{5}$，所以 $CG = BC \cdot \sin B = 5 \times \frac{4}{5} = 4$；再由勾股定理得 $BG = \sqrt{BC^2 - CG^2} = \sqrt{25 - 16} = 3$。  
第三步：因为 $AB = 9$，所以 $AG = AB - BG = 9 - 3 = 6$；又 $\angle AGC = 90^\circ$，所以在 $\triangle AGC$ 中，$\tan \angle BAC = \frac{CG}{AG} = \frac{4}{6} = \frac{2}{3}$。  
第四步：观察 $\triangle PCF$：已知 $\angle CPF = 90^\circ$，且 $\frac{FP}{PC} = \frac{2}{3}$，所以在 $\triangle PCF$ 中，$\tan \angle PCF = \frac{FP}{PC} = \frac{2}{3}$。  
第五步：由于 $\angle BAC$ 和 $\angle PCF$ 都是锐角，且正切值相等，因此 $\angle BAC = \angle PCF$。

**第（2）问：当 $\triangle APC \sim \triangle EFC$ 时，求 $BP$ 的长**

第一步：利用平行四边形性质，$AB \parallel CD$，所以 $\angle BAC = \angle ACD$（内错角相等）。  
第二步：由第（1）问结论 $\angle PCF = \angle BAC$，可得 $\angle PCF = \angle ACD$，进而推出 $\angle PCA = \angle FCD$。  
第三步：由 $\triangle APC \sim \triangle EFC$，对应顶点顺序为 $A \leftrightarrow E$、$P \leftrightarrow F$、$C \leftrightarrow C$，所以 $\angle APC = \angle EFC$；又因 $B$、$P$、$A$ 共线，故 $\angle BPC = \angle PFC$。  
第四步：在 $\triangle BPC$ 中，$\cot \angle BPC = \frac{PG}{CG}$；在 $\triangle PFC$ 中，$\cot \angle PFC = \frac{FP}{PC} = \frac{2}{3}$；所以 $\frac{PG}{CG} = \frac{2}{3}$。  
第五步：代入 $CG = 4$，得 $PG = \frac{2}{3} \times 4 = \frac{8}{3}$；而 $BG = 3$，所以 $BP = BG + GP = 3 + \frac{8}{3} = \frac{17}{3}$。

**第（3）问：当 $\frac{S_{\triangle HFC}}{S_{\triangle PHC}} = \frac{1}{3}$ 时，求 $\frac{AH}{AC}$ 的值**

第一步：过点 $H$ 作 $HM \perp AB$，垂足为点 $M$。  
第二步：注意到 $\angle FPC = 90^\circ$，所以 $\angle MPH = \angle PCG$；又 $\angle HMP = \angle CGP = 90^\circ$，因此 $\triangle MPH \sim \triangle GCP$。  
第三步：由面积比 $\frac{S_{\triangle HFC}}{S_{\triangle PHC}} = \frac{1}{3}$，且两三角形同高（以 $HC$ 为底时高均为点 $F$、$P$ 到直线 $HC$ 的距离），得 $\frac{FH}{PH} = \frac{1}{3}$。  
第四步：分两种情况讨论点 $F$ 相对于线段 $PH$ 的位置：

① 当点 $F$ 在线段 $PH$ 的延长线上时：由 $\frac{FP}{PC} = \frac{2}{3}$ 及 $\frac{FH}{PH} = \frac{1}{3}$，可推出 $\frac{PH}{PC} = \frac{1}{2}$；设 $MH = a$，则由相似比得 $GP = 2a$，$MP = 2$；又 $AG = 6$，$BG = 3$，所以 $AM = AG - MG = 6 - (GP + PM) = 6 - (2a + 2)$；但更直接地，由 $AB = AM + MP + PG + GB = 9$，即 $AM + 2 + 2a + 3 = 9$，解得 $AM = 4 - 2a$；又由 $\triangle AGC$ 中 $\frac{AM}{AG} = \frac{MH}{CG} = \frac{a}{4}$，即 $\frac{AM}{6} = \frac{a}{4}$，得 $AM = \frac{3}{2}a$；联立 $\frac{3}{2}a = 4 - 2a$，解得 $a = \frac{8}{7}$；于是 $\frac{AH}{AC} = \frac{MH}{CG} = \frac{a}{4} = \frac{2}{7}$。

② 当点 $F$ 在线段 $PH$ 上时：由 $\frac{FH}{PH} = \frac{1}{3}$ 得 $PF = PH - FH = \frac{2}{3}PH$，结合 $\frac{FP}{PC} = \frac{2}{3}$，得 $PH = PC$；设 $MH = b$，则由 $\triangle MPH \sim \triangle GCP$ 得 $GP = b$，$MP = 4$；再由 $AB = AM + MP + PG + GB = 9$，即 $AM + 4 + b + 3 = 9$，得 $AM = 2 - b$；又由 $\frac{AM}{AG} = \frac{MH}{CG} = \frac{b}{4}$，即 $\frac{AM}{6} = \frac{b}{4}$，得 $AM = \frac{3}{2}b$；联立 $\frac{3}{2}b = 2 - b$，解得 $b = \frac{4}{5}$；于是 $\frac{AH}{AC} = \frac{MH}{CG} = \frac{b}{4} = \frac{1}{5}$。

综上，$\frac{AH}{AC}$ 的值为 $\frac{2}{7}$ 或 $\frac{1}{5}$。
