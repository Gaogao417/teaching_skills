### Q24(3)续 @page33-34
TYPE: solve
STEM: (承接前页 Q24(3))
SOLUTION:
$\because y = -\dfrac{1}{2}x^2 + mx - \dfrac{1}{2}m^2 + m + 1 = -\dfrac{1}{2}(x-m)^2 + m+1$
$\therefore$ 顶点 $A(m, m+1)$，$B\!\left(0,\, -\dfrac{1}{2}m^2 + m + 1\right)$，$C\!\left(2m,\, -\dfrac{1}{2}m^2 + m + 1\right)$
$\because$ 沿射线 $CA$ 方向平移，$\therefore BC = B'C'$，$BC \parallel B'C'$，$\therefore \triangle ADC' \sim \triangle ABC$
$\therefore \left(\dfrac{C'D}{BC}\right)^2 = \dfrac{1}{9}$，$\therefore \dfrac{C'D}{BC} = \dfrac{1}{3}$
$\because BC = B'C' = 2m$，$\therefore C'D = \dfrac{2}{3}m$
$\because MC' = \dfrac{1}{2}B'C' = m$，$\therefore MD = MC' - DC' = \dfrac{1}{3}m$
$\because \tan\angle A'DB' = \dfrac{A'M}{DM} = 4$
$\therefore \dfrac{m + 1 - \left(-\dfrac{1}{2}m^2 + m + 1\right)}{\dfrac{1}{3}m} = 4$
解得：$m = \dfrac{8}{3}$ 或 $m = 0$（舍）
$\therefore A\!\left(\dfrac{8}{3},\, \dfrac{11}{3}\right)$
ANSWER: $A\!\left(\dfrac{8}{3},\, \dfrac{11}{3}\right)$

### Q25 @page34-39
TYPE: solve
STEM: 已知在 $\triangle ABC$ 中，$\angle ABC = 90°$，$BD$ 是边 $AC$ 上的中线。以点 $B$ 为圆心，$BD$ 为半径的圆交线段 $CD$ 于点 $E$（点 $E$ 不与点 $C$、点 $D$ 重合）。
(1) 如图1，如果 $\odot B$ 与边 $BC$ 交于点 $F$，$\overset{\frown}{FE} = \overset{\frown}{DE}$，求 $\angle DBE$ 的度数；
(2) 如图2，当 $AE = 5EC$ 时，求 $\angle C$ 的正切值；
(3) 如图3，以点 $E$ 为圆心，$BC$ 为半径的 $\odot E$ 与 $\odot B$ 相交，其中一个交点 $P$ 在边 $AB$ 上。如果 $BD = 1$，求 $AE$ 的长。
[FIG1: 直角三角形 ABC，∠ABC=90°，BD 为 AC 中线，⊙B 交 AC 于 D、E，交 BC 于 F]
[FIG2: 同构，E 位置不同，AE=5EC]
[FIG3: ⊙B 与 ⊙E 相交，交点 P 在 AB 上]
SOLUTION:
【小问1详解】
$\because \overset{\frown}{FE} = \overset{\frown}{DE}$，$\therefore \angle 1 = \angle 2$，设 $\angle 1 = \angle 2 = \alpha$
$\because \angle ABC = 90°$，$BD$ 是中线，$\therefore DB = DC = DA$，$\therefore \angle C = \angle DBC = 2\alpha$
$\therefore \angle 3 = \angle C + \angle 1 = 3\alpha$
$\because BD = BE$，$\therefore \angle 3 = \angle 4 = 3\alpha$
在 $\triangle BDE$ 中，$3\alpha + 3\alpha + \alpha = 180°$，$\therefore \alpha = \dfrac{180°}{7}$，即 $\angle DBE = \dfrac{180°}{7}$
【小问2详解】
过点 $B$ 作 $BK \perp AC$ 于点 $K$，$\because BK$ 过圆心，$\therefore DK = EK$
设 $EC = m$，则 $AE = 5m$，$AC = 6m$，$DB = DC = DA = 3m$，$DE = 2m$，$DK = EK = m$
$BK = \sqrt{BD^2 - DK^2} = 2\sqrt{2}\,m$
$\tan C = \dfrac{BK}{CK} = \dfrac{2\sqrt{2}\,m}{2m} = \sqrt{2}$
【小问3详解】
连接 $PE$，$\because BE = BD = BP = CD = AD = 1$，且 $BC = EP$
$\therefore \triangle DBC \cong \triangle DPE$（SSS），$\therefore \angle CDB = \angle EBP$
$\therefore \angle DEB = \angle BEA$，$\therefore \triangle DEB \sim \triangle BEA$
$\therefore \dfrac{BE}{AE} = \dfrac{ED}{BE}$
设 $AE = x$，则 $DE = x - 1$，$\therefore \dfrac{1}{x} = \dfrac{x-1}{1}$
$x^2 - x - 1 = 0$，解得 $x = \dfrac{1+\sqrt{5}}{2}$（负值舍）
ANSWER: (1) $\angle DBE = \dfrac{180°}{7}$；(2) $\tan C = \sqrt{2}$；(3) $AE = \dfrac{1+\sqrt{5}}{2}$
