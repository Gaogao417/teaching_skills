这道证明题两小问，第一问条件是 at 乘 op 等于 op 乘 ot，我们把它交叉改写成比例式 at 比 ot 等于 op 比 op。观察图形，b d 是 x 边上的高，所以角 a d b 和角 o d c 都是直角，两组边成比例且夹角相等，用 sss 相似得到直角三角形 a d b 相似于直角三角形 o d c，相似之后倒角可以推出角 x 等于角直角相关的关系，从而证明测垂直于 l。第二问 f 是角 box 的平分线，交 b c 于 f，交得于 g，要证 f 乘得等于 x 乘 b c，我们先把它改写成比例式 f 比 x 等于 b c 比得，再去找分别含有这四条边的两组相似三角形，用公共角加平行或等角替换，把两条比例串起来，比例式就得证了。
