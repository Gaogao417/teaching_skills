我们来逐步分析这道题。请先看图，明确图形结构：在 Rt$\triangle ABC$ 和 Rt$\triangle ACD$ 中，已知 $AC = BC$，$\angle ACB = 90^\circ$，$\angle ADC = 90^\circ$，$CD = 2$，点 $A$、$B$ 分别在直线 $CD$ 的两侧；射线 $CD$ 交边 $AB$ 于点 $E$；点 $G$ 是 Rt$\triangle ABC$ 的重心；射线 $CG$ 交边 $AB$ 于点 $F$；设 $AD = x$，$CE = y$。

第（1）问：求证 $\angle DAB = \angle DCF$。  
首先，观察 Rt$\triangle ABC$：因为 $AC = BC$ 且 $\angle ACB = 90^\circ$，所以它是等腰直角三角形；又点 $G$ 是它的重心，而 $CG$ 的延长线交 $AB$ 于点 $F$，所以 $CF$ 是中线；在等腰直角三角形中，斜边上的中线也是高线和角平分线，因此 $CF \perp AB$，即 $\angle AFC = 90^\circ$。  
接着，注意到 $\angle ADE = 90^\circ$（因 $\angle ADC = 90^\circ$），$\angle EFC = 90^\circ$（因 $CF \perp AB$），所以在四边形 $ADFE$ 中，$\angle DAE + \angle ADE = \angle ECF + \angle EFC$；两边同时减去直角，得 $\angle DAB = \angle DCF$。  

第（2）问：当点 $E$ 在边 $CD$ 上时，求 $y$ 关于 $x$ 的函数关系式，并写出 $x$ 的取值范围。  
第一步，过点 $B$ 作 $BH \perp CD$，垂足为 $H$；第二步，证明 $\triangle CAD \cong \triangle BCH$：因为 $\angle CAD = \angle BCH = 45^\circ$，$\angle CDA = \angle BHC = 90^\circ$，且 $AC = BC$，所以两三角形全等；于是 $BH = CD = 2$，$CH = AD = x$，从而 $DH = CD - CH = 2 - x$。  
第三步，由 $AD \parallel BH$（同垂直于 $CD$），得比例关系 $\frac{AD}{BH} = \frac{DE}{EH}$，即 $\frac{x}{2} = \frac{DE}{EH}$；变形得 $\frac{x + 2}{2} = \frac{DE + EH}{EH} = \frac{DH}{EH}$，解得 $EH = \frac{4 - 2x}{x + 2}$。  
第四步，计算 $y = CE = CH + HE = x + \frac{4 - 2x}{x + 2} = \frac{x^{2} + 4}{x + 2}$；由于点 $E$ 在线段 $CD$ 上，且 $C$、$D$ 之间长度为 $2$，故 $0 < x \leq 2$。  

第（3）问：如果 $\triangle CDG$ 是以 $CG$ 为腰的等腰三角形，求 $AD$ 的长。  
“以 $CG$ 为腰”说明有两种可能：$GC = GD$ 或 $CG = CD$。  
第一种情况：$GC = GD$。取 $AC$ 中点 $M$，连接 $MD$、$MG$；由等腰直角三角形性质知 $MD = MC$，且 $MG \perp CD$，又 $BH \perp CD$，故 $MG$ 与 $BH$ 共线；结合 $CH = AD = x$ 及几何位置可得 $x = 1$。  
第二种情况：$CG = CD = 2$。因 $G$ 是 $\triangle ABC$ 的重心，故 $CF = \frac{3}{2} CG = 3$；又 $CF$ 是斜边 $AB$ 上的中线，所以 $AB = 2CF = 6$；在等腰直角 $\triangle ABC$ 中，$AC = BC = \frac{\sqrt{2}}{2} AB = 3\sqrt{2}$；再在 Rt$\triangle ACD$ 中，由勾股定理得 $AD = \sqrt{AC^{2} - CD^{2}} = \sqrt{18 - 4} = \sqrt{14}$。  
综上，$AD = 1$ 或 $\sqrt{14}$。
